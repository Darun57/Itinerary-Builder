# Goa Destination Data Notes

This variant keeps the Velqairn application architecture and features while replacing the destination catalog with a Goa-focused catalog.

## Destination reference sources
- Goa Tourism Development Corporation (Government of Goa): destination, beach, fort, waterfall, heritage and activity references.
- Government of Goa accommodation pages: GTDC accommodation properties and area groupings.
- Official hotel brand pages used to verify a selection of current Goa hotel properties and positioning, including Marriott Bonvoy, Hyatt, ITC Hotels, Accor, Radisson and other official property pages.

## Important catalog rules
- Hotel records are a curated product catalog, not live availability. `availability_status` means usable in the demo/catalog; it does not confirm real-time inventory.
- Activity prices are indicative planning values, not live supplier quotations. Confirm current rates, operating days, permit rules, sea conditions and access rules before selling an itinerary.
- Ferry/river-transfer timings are illustrative catalog values and must be confirmed with the local operator before booking.
- The bundled visuals are lightweight Goa-themed placeholders so the package does not ship the original Andaman photography. Replace these with licensed/owned Goa photography before commercial launch.
